# Site source

The live site is the single file `index.html` in the repo root. It is generated by `source/build.py`, so make changes here and rebuild instead of hand-editing `index.html`.

## Rebuild

```bash
python3 source/build.py
```

This needs only Python 3 (no packages). It overwrites `index.html` in the repo root. Commit and push, and GitHub Pages updates the live site within a minute or two.

## Where things live

| What you want to change | Where |
| --- | --- |
| Job entries on the Experience page | `source/content/experience.html` |
| Degree card on the Studies page | `source/content/education.html` |
| "Where I'm headed" cards on the Studies page | `source/content/focus.html` |
| Hobby cards on the Off the clock page | `source/content/life.html` |
| Name, tagline, About text, sea glass quote, contact, capstone project | `source/build.py` (search for the text) |
| Page intros under each title | `source/build.py`, the `view(...)` calls |
| Colors, fonts, layout | the `<style>` block in `source/build.py` |
| Arch illustrations (beach, midday, Golden Gate, sunset) | `shore_bg`, `morning_arch`, `gg_arch`, `sunset_arch` in `source/build.py` |
| Sea glass shapes and colors | `GLASS` in `source/build.py` |
| Résumé | replace `resume.pdf` in the repo root |

## How the site works

- The home page shows three framed arches, one per sea glass piece. Each opens its own page: Experience (white pebble, midday beach), Studies (amber piece, Golden Gate in the afternoon), Off the clock (green star, sunset).
- Pages switch with the URL hash (`#experience`, `#studies`, `#life`); there is no framework.
- `CNAME` holds the custom domain (`briennabrandau.com`). Keep it.
- Fonts come from Google Fonts (Cormorant Garamond and Jost). Everything else is inline in `index.html`.
